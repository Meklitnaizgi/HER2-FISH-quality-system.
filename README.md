# HER2 FISH Testing: Quality System Document Package

A self-directed project applying medical device quality system methods (**ISO 13485** and **ISO 14971**) to the HER2 FISH breast cancer test, from pretreatment to final report.

**Goal:** show how a clinical lab process can be managed with the same quality tools used to design and make medical devices.

> **Note:** All data in this project is simulated. It is based on public standards and general lab practice, and it is not an official Mayo Clinic document.

## Documents

| # | Document | Outcome |
|---|---|---|
| 1 | Risk analysis (FMEA) | 4 key risks found; top risk (scoring outside the tumor area) reduced from RPN 120 to 60 |
| 2 | Work instruction WI-005 | Denaturation and hybridization written as a controlled document |
| 3 | Process validation PV-003 | ThermoBrite and humidified incubator passed IQ, OQ, and PQ (12 of 12 runs) |
| 4 | Acceptance procedure AP-004 | New probe lot passed receiving inspection and parallel testing |
| 5 | Design controls DC-006 | Scoring worksheet traced from user needs to verification and validation |
| 6 | CAPA-2026-012 | Weak-signal failures (10% of runs) traced to root cause; 0 failures in 52 runs after the fix |
| 7 | CLIA vs. ISO 13485 crosswalk | Lab practices mapped to ISO 13485 clauses |
